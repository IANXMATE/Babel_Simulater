## 1. GT 训练数据架构（Dataset 输入格式）

### 1.1 数据集来源

由 `step3_build_transformer_dataset_v0.py` 从原始字体拓扑 JSON 生成，使用以下配置：

```python
MAX_ORDER_SAMPLES = 1   # 不使用顺序增强
ROTATION_MODE = 0       # 关闭旋转增强（旋转后 edge_ts 不变但坐标改变，造成同输入多GT歧义）
MIRROR_MODE = False     # 关闭镜像增强（同上）
```

**关闭旋转/镜像增强的原因**：旋转后 `edge_ts`（t 值、角度）完全不变，但坐标 GT 不同，造成"同输入→8种GT坐标"的矛盾监督信号，模型只能学到所有方向的均值，预测精度极差。

### 1.2 每个样本的数据结构（JSON）

```json
{
  "char": "字符",
  "derivation": "order_0_rot0_mxFalse_myFalse",
  "num_nodes": 3,
  "nodes": [
    {
      "node_id": 0,
      "shape_code": 14,       // 笔画形状编码（0~999）
      "width_token": 0,       // 笔画宽度 token（0~3）
      "p0_cell": [20, 15],    // 起点格子坐标
      "p0_offset": [0, 0],    // 起点偏移
      "p3_cell": [11, 15],    // 终点格子坐标
      "p3_offset": [0, 0]     // 终点偏移
    }
  ],
  "edges": [
    {
      "u": 0, "v": 1,
      "j_type": "X",         // 拓扑关系：NONE/E2E/X/T
      "j_type_idx": 2,       // 对应整数：0/1/2/3
      "t_u": 0.49,           // 交点在笔画 u 的参数位置 ∈ [0,1]
      "t_v": 0.857,          // 交点在笔画 v 的参数位置 ∈ [0,1]
      "t_diff": 0.367,       // |t_u - t_v|
      "t_prod": 0.419,       // t_u * t_v
      "angle_sin": 1.0,      // sin(交叉角度)，范围 ≥ 0
      "angle_cos": -0.0017   // cos(交叉角度)，范围 [-1,1]
    }
  ]
}
```

### 1.3 角度字段约定

| 拓扑类型 | angle 来源 | angle_sin | angle_cos |
|---------|-----------|-----------|-----------|
| **E2E** | 固定 180°（端对端，切线反向） | 0.0 | -1.0 |
| **X** | 存储在 topo JSON 的 `angle` 字段 | sin(rad) | cos(rad) |
| **T** | 存储在 topo JSON 的 `angle` 字段 | sin(rad) | cos(rad) |
| **NONE** | 无连接，填充默认 0° | 0.0 | 1.0 |

**注意**：`angle_sin` 始终 ≥ 0（只存角度大小，不含方向符号）。

### 1.4 Dataset 预处理

```python
# 坐标归一化：cell 坐标 / 32.0 → 约 ∈ [0, 1]
p0_x = (p0_cell[0] + p0_offset[0]) / 32.0

# 字形中心化：去除绝对位置信息
all_pts = coords[:num_nodes].view(-1, 2)   # [2N, 2]
center = all_pts.mean(dim=0)
coords[:num_nodes, 0:2] -= center          # P0 -= center
coords[:num_nodes, 2:4] -= center          # P3 -= center
```

中心化后坐标约 ∈ [-0.5, 0.5]，**但不作为模型输入，只作为 Loss 的监督目标**。

### 1.5 模型真正的输入（推理时完全可用）

```
edge_types: [B, N, N]     int64   拓扑边类型（0:NONE / 1:E2E / 2:X / 3:T）
edge_ts:    [B, N, N, 6]  float32 边几何特征 [t_u, t_v, t_diff, t_prod, angle_sin, angle_cos]
mask:       [B, N]        bool    True = padding 节点
```

shapes/widths/coords **不传入模型**，只作为 Loss 监督信号。

## 2. 模型架构（FontGraphGenerator）

### 2.1 超参数

```python
D_MODEL = 256    # 节点嵌入维度
D_EDGE  = 64     # 边特征维度
N_HEADS = 8      # 注意力头数
N_LAYERS = 6     # Transformer 层数
DROPOUT = 0.1
MAX_NODES = 50   # 最大节点数（用于 NodeIdEmb）
NUM_SHAPES = 1000
NUM_WIDTHS = 4
NUM_EDGE_TYPES = 4  # 0:NONE 1:E2E 2:X 3:T
```

### 2.2 整体前向流程

```
输入：edge_types [B,N,N], edge_ts [B,N,N,6], mask [B,N]
         │
         ├─── TopoNodeEncoder ──────────────────────┐
         │    (边聚合 → 节点嵌入)                    │
         │                                           │
         ├─── NodeIdEmb(0..N-1) [B,N,D_MODEL]      │
         │                                           ▼
         │                               x = NodeIdEmb + TopoNodeEnc
         │                                     [B, N, D_MODEL]
         │
         ├─── edge_attr = EdgeTypeEmb + EdgeTMLP  [B,N,N,D_EDGE]
         │
         └─── GraphTransformer × 6 层
                    (EdgeAwareAttention + MLP)
                         │
                    LayerNorm
                         │
               ┌─────────┼────────────────┐
               ▼         ▼                ▼
          decode_shape  decode_width   decode_coords   decode_edge
          [B,N,1000]   [B,N,4]       [B,N,4]+Tanh    [B,N,N, 4+2+2]
```

### 2.3 TopoNodeEncoder（拓扑感知节点编码器）

```python
# 对节点 i，聚合所有出边 (i→j) 的特征
type_e = Embedding(NUM_EDGE_TYPES, D_EDGE)(edge_types)  # [B,N,N,D_EDGE]
t_e    = Linear(6, D_EDGE)(edge_ts)                     # [B,N,N,D_EDGE]
edge_feat = MLP(D_EDGE*2 → D_MODEL)(concat(type_e, t_e)) # [B,N,N,D_MODEL]

# Mean pooling（只聚合 type>0 的有效边）
valid_mask = (edge_types > 0).float()  # [B,N,N,1]
node_emb = mean_pool(edge_feat, dim=j, mask=valid_mask)  # [B,N,D_MODEL]
```

### 2.4 EdgeAwareGraphAttention

标准 Multi-Head Attention + **edge feature 作为 attention bias**：

```
A_ij = (Q_i · K_j) / √d_k  +  W_e(edge_attr[i,j])
```

```python
scores = Q @ K.T / sqrt(d_k)           # [B, H, N, N]
edge_bias = Linear(D_EDGE, H)(edge_attr)  # [B, N, N, H] → permute → [B,H,N,N]
scores = scores + edge_bias             # edge 信息融入注意力权重
```

### 2.5 解码器

#### 坐标解码（decode_coords）
```python
nn.Sequential(
    Linear(D_MODEL, 128),
    GELU(),
    Linear(128, 4),
    Tanh()   # 输出 ∈ [-1,1]，对应 [P0_x, P0_y, P3_x, P3_y]
)
```
输出 [P0_x, P0_y, P3_x, P3_y]，Tanh 空间 ∈ [-1, 1]。

#### 边几何解码（decode_edge）
```python
# 输入：节点对 [x_i || x_j]，维度 D_MODEL*2
nn.Sequential(
    Linear(D_MODEL*2, 128),
    GELU(),
    Linear(128, NUM_EDGE_TYPES + 4)  # 4类型logits + [t_u, t_v, sin_raw, cos_raw]
)
```

后处理：
```python
edge_type_logits = edge_raw[..., :4]           # 直接 softmax
edge_geom = sigmoid(edge_raw[..., 4:])         # ∈ [0,1]
t_pred      = edge_geom[..., :2]               # t_u, t_v ∈ [0,1]
angle_raw   = edge_geom[..., 2:]               # ∈ [0,1]
angle_pred  = angle_raw * 2.0 - 1.0           # 映射到 [-1,1]

edge_preds = concat([edge_type_logits, t_pred, angle_pred], dim=-1)
# 最终维度: [B, N, N, 8]
# 索引：[:4]=类型logits, [4:6]=t_u/t_v, [6:8]=angle_sin/cos
```

### 2.6 参数量估计

| 模块 | 参数量（约） |
|------|------------|
| TopoNodeEncoder | ~200K |
| NodeIdEmb (50×256) | 12.8K |
| EdgeTypeEmb (4×64) | 0.3K |
| EdgeTMLP (6→64→64) | ~4K |

## 3. Loss 函数设计

### 3.1 超参数

```python
LAMBDA_EDGE        = 1.0   # L_edge 总权重
LAMBDA_T           = 5.0   # L_t 子项权重（BCE，因为 t 值为 0/1 二值）
LAMBDA_JUNCTION    = 5.0   # L_junction 物理交点约束
LAMBDA_COORD_ANGLE = 3.0   # L_coord_angle 坐标切线角度约束
LAMBDA_REPULSE     = 2.0   # L_repulse 节点互斥力
MIN_NODE_DIST_SQ   = 0.04  # 节点间最小距离² = 0.2²
LAMBDA_ANGLE       = 1.0   # L_angle 辅助监督（edge_preds 的 angle_sin/cos）
LAMBDA_LENGTH      = 5.0   # L_length 笔画长度监督
```

### 3.2 各项 Loss 详细

```
Total = L_node + λ_edge×L_edge + λ_angle×L_angle
      + λ_junction×L_junction + λ_coord_angle×L_coord_angle + λ_repulse×L_repulse
```

#### L_node（节点属性损失）
```python
L_shape  = CrossEntropy(shape_logits, gt_shapes)
L_width  = CrossEntropy(width_logits, gt_widths)

# 笔画长度（平移不变量，不引起均值坍塌）
pred_len = ||(P3_pred - P0_pred)||   # [B, N]
gt_len   = ||(P3_gt - P0_gt)||
L_length = SmoothL1(pred_len, gt_len)

L_node = L_shape + L_width + LAMBDA_LENGTH × L_length
```

#### L_edge（边预测损失）
```python
L_edge_type = CrossEntropy(edge_type_logits, gt_edge_types)

# t 值：E2E/T 类型为二值（0或1），用 BCE；X 类型为任意小数，用 SmoothL1
# ⚠️ 必须分类型处理！E2E/T 用 BCE 是因为 GT 只有 0 和 1
for E2E, T edges:
    L_t += BCE(tu_pred, gt_tu) + BCE(tv_pred, gt_tv)
for X edges:
    L_t += SmoothL1(tu_pred, gt_tu) + SmoothL1(tv_pred, gt_tv)
L_t /= num_types_present

L_edge = L_edge_type + LAMBDA_T × L_t
```

#### L_angle（edge_preds 角度辅助监督）
```python
# 监督 decode_edge 输出的 angle_sin/cos（辅助，不直接约束坐标方向）
L_angle = SmoothL1(angle_sin_pred, gt_sin) + SmoothL1(angle_cos_pred, gt_cos)
```

#### L_junction（物理交点约束）⚠️ 使用 GT t，不用预测 t
```python
# ⚠️ 关键：用 GT t 值计算交点，不用预测 t
# 用预测 t 会给坐标错误的梯度方向（训练初期预测 t 不准）
pt_i = P0_i*(1-gt_tu) + P3_i*gt_tu    # 交点在笔画 i 上的坐标
pt_j = P0_j*(1-gt_tv) + P3_j*gt_tv    # 交点在笔画 j 上的坐标

dist_sq = ||pt_i - pt_j||²
dist_l1 = |pt_i - pt_j|₁

L_junction = mean(dist_sq + 0.1×dist_l1)  # 仅对有效边（type>0）
```

#### L_coord_angle（坐标切线角度约束）cos+|sin| 双通道
```python
# 直接约束预测坐标使得两笔画在交点处的夹角符合 GT
vec_i = normalize(P3_i - P0_i)   # 笔画 i 的方向向量（单位化）
vec_j = normalize(P3_j - P0_j)

cos_actual = dot(vi, vj)                         # ∈ [-1,1]
sin_actual = |vi[0]*vj[1] - vi[1]*vj[0]|        # |cross product| ∈ [0,1]
# 取绝对值：GT angle_sin 始终 ≥ 0，有符号 cross 会造成 T 型方向歧义

L_coord_angle = SmoothL1(cos_actual, gt_cos) + SmoothL1(sin_actual, gt_sin)
```

**为什么 sin 要取绝对值**：GT `angle_sin = sin(θ) ≥ 0`（只存角度大小）。Cross product 是有符号量，同一个 90° 夹角根据笔画方向排列可能得到 +1 或 -1。若不取绝对值，模型会被推向 180°（cos=-1, sin=0）而非 90°（cos=0, |sin|=1）。

#### L_repulse（节点互斥力）
```python
# 防止所有节点中心点坍塌到同一位置
mid_i = (P0_i + P3_i) / 2   # 节点中心点
dist_sq = ||mid_i - mid_j||²

L_repulse = mean(ReLU(MIN_NODE_DIST_SQ - dist_sq))  # 仅当距离 < 0.2 时有梯度
# 使用平方距离而非欧式距离，避免 sqrt 在 dist=0 时导数爆炸
```

## 4. 推理脚本（stage1_inference.py）

### 4.1 推理流程概览

```
手工拓扑输入
    │  edge_types [N,N], edge_ts [N,N,6]
    ▼
FontGraphGenerator.forward()
    │  输入：unsqueeze(0) 加 batch 维，mask=全零
    ▼
模型输出：
  coords_pred [1,N,4]  ← Tanh 空间 [-1,1]
  edge_preds  [1,N,N,8]
    │
    ▼
坐标还原：(coords_raw + 1.0) / 2.0 * 400.0  → 像素空间 [0, 400]
    │
    ▼
物理 Solver（端点吸附）
  使用输入拓扑的权威 t 值，不用模型预测的 t
    │
    ▼
渲染输出（左：原始 / 右：Solver 后）
```

### 4.2 拓扑输入格式（6 维 edge_ts）

```python
# edge_ts[i,j] = [t_u, t_v, t_diff, t_prod, angle_sin, angle_cos]

# E2E（端到端）：t_u=1.0(i的P3端), t_v=0.0(j的P0端), angle=180°
ts[i, j] = [1.0, 0.0, 1.0, 0.0, 0.0, -1.0]

# T 型：t_u=0.5(i的中点), t_v=0.0(j的P0端), angle=90°
ts[i, j] = [0.5, 0.0, 0.5, 0.0, 1.0, 0.0]

# X 型（十字交叉）：两个内部参数位置，angle 取实际夹角
ts[i, j] = [0.49, 0.86, 0.37, 0.42, 1.0, 0.0]  # 示例

# 注意：edge_ts 是对称填写的，[i,j] 和 [j,i] 的 t_u/t_v 互换
ts[j, i] = [t_v, t_u, t_diff, t_prod, angle_sin, angle_cos]
```

### 4.3 物理 Solver 算法

```python
THRESH = 0.05  # 判断是否为端点的阈值

for i in range(N):
    for j in range(i+1, N):  # 只处理上三角，每条无向边处理一次
        et = edge_types[i,j]
        if et == 0: continue

        tu = topo_ts[i,j,0]   # 交点在 Node_i 的参数位置
        tv = topo_ts[i,j,1]   # 交点在 Node_j 的参数位置

        # 计算交点坐标（用输入的权威 t 值）
        pt_i = coords[i,:2]*(1-tu) + coords[i,2:]*tu
        pt_j = coords[j,:2]*(1-tv) + coords[j,2:]*tv

        i_is_end = (tu < THRESH) or (tu > 1-THRESH)
        j_is_end = (tv < THRESH) or (tv > 1-THRESH)

        if i_is_end and j_is_end:
            # E2E：两端点对接 → 吸附到均值
            junc = (pt_i + pt_j) / 2.0
            if tu < 0.5: coords[i,:2] = junc  # 修改 P0 端
            else:        coords[i,2:] = junc  # 修改 P3 端
            if tv < 0.5: coords[j,:2] = junc
            else:        coords[j,2:] = junc

        elif i_is_end:
            # i 端点 → j 内部点（j 是权威，j 的内部位置不变）
            junc = pt_j
            if tu < 0.5: coords[i,:2] = junc
            else:        coords[i,2:] = junc

        elif j_is_end:
            # j 端点 → i 内部点（i 是权威，i 的内部位置不变）
            junc = pt_i
            if tv < 0.5: coords[j,:2] = junc
            else:        coords[j,2:] = junc

        else:
            # X 型：两个内部点 → 均值（不移动端点，保持笔画长度）
            junc = (pt_i + pt_j) / 2.0
            # （目前仅记录，X 型坐标不做 Solver 吸附）
```

**关键设计决策**：
- Solver 使用**输入的拓扑 t 值**（权威），而非模型预测的 t 值。模型预测的 t 仅用于调试诊断打印。
- 每条无向边只处理一次（`j > i`），避免双向覆盖造成坐标冲突。
- T 型中，"内部点"（如 t=0.5 的一侧）是**权威**，端点侧吸附过去，不移动内部点。

### 4.4 坐标空间变换

```python
# 模型输出：Tanh ∈ [-1, 1]（中心化坐标空间）
# 推理还原到像素空间：
coords_pixel = (coords_tanh + 1.0) / 2.0 * CANVAS_SIZE  # CANVAS_SIZE = 400

# 训练时的 GT：/ 32.0 归一化 + 中心化，约 ∈ [-0.5, 0.5]
# ⚠️ 训练坐标空间（约±0.5）与 Tanh 输出空间（±1）有 2× 的尺度差
# 实际训练中模型学习的是相对比例，推理时映射到 [0,400] 像素
```

## 6. 关键设计决策与历史修复

### Bug 修复记录

| Bug | 现象 | 根因 | 修复方法 |
|-----|------|------|---------|
| 旋转增强歧义 | 相同输入多种GT坐标 | rot0/90/180/270 edge_ts 完全一样 | 关闭 ROTATION_MODE 和 MIRROR_MODE |
| L_junction 用错 t | 坐标方向错误，角度不准 | 用了预测 t 而非 GT t 计算交点 | 改为用 `gt_edge_ts[...,0/1]` |
| t 值不收敛（MAE≈0.22） | 模型预测 t 停在 0.5 | SmoothL1 在 0/1 二值GT时梯度太弱 | 改 E2E/T 为 BCE Loss |
| L_coord_angle sin 歧义 | T 型角度变差（126→167°） | 有符号 cross product 方向不定 | 改用 `|cross product|` |
| Solver 双向覆盖 | 端点被压缩 | 双向循环造成后写覆盖前写 | 改为 `j > i` 单向循环 |
| Solver 使用预测 t | 接合点位置不准 | Solver 用了 `edge_preds` 的 t | 改为直接使用输入的 `topo_ts` |

### 架构设计原则

1. **训练-推理对齐**：模型输入只有 `edge_types` 和 `edge_ts`，推理时完全可用，无 train-test gap。
2. **平移不变监督**：`L_length` 监督 `||P3-P0||`（相对差），不监督绝对坐标，防止均值坍塌。
3. **GT t 优先于预测 t**：`L_junction` 和 Solver 都使用 GT/输入的权威 t 值，预测 t 仅作辅助监督用于衔接 stage2。
4. **分类型 t Loss**：E2E/T 的 t 值是严格 0/1，用 BCE；X 的 t 是连续值，用 SmoothL1。
5. **|cos|+|sin| 双通道角度**：避免 cos 偶函数的方向歧义（90°=270°），`|sin|` 则解决笔画方向符号歧义。
